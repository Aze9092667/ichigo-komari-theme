# Ichigo · BLEACH — Komari 主题

为 Komari 定制的 BLEACH 风格监控主题。当前版本 **1.2.3-aze.35**，使用橙色背景、BLEACH 角色拼图、暖色磨砂玻璃卡片和骷髅牌图标。

![主题预览](preview.png)

## 安装

1. 打开 [Releases](https://github.com/Aze9092667/ichigo-komari-theme/releases/latest)。
2. 下载附件 **`Ichigo-Komari-Theme.zip`**。
3. 在 Komari 后台 → 主题管理 → 上传主题，上传 ZIP 后启用。

也可在支持 URL 导入的 Komari 后台使用以下地址：

```text
https://github.com/Aze9092667/ichigo-komari-theme/releases/latest/download/Ichigo-Komari-Theme.zip
```

请下载 Release 附件；GitHub 自动生成的 Source code ZIP 是维护源码，不是直接安装包。兼容性已在 Komari 1.6.1 上验证。

## 功能

- 完整的一护角色演变拼图、纯白的日文「BLEACH 千年血戦篇」矢量页头标志及统一骷髅牌图标；隐藏右下角浮动角色与对话气泡。
- 首页开场动画依次划线、呈现日文标志并揭开官网背景。背景已放大和轻微锐化；开启系统的「减少动态效果」时会跳过开场。
- 概览、地图、服务器卡片、筛选栏与搜索框统一使用磨砂玻璃；本地链路、三网回程和拨测表共用浅色透明内层，布局高度保持一致。
- 视图切换图标保持清晰，监控标题和刷新提示使用增强对比度，顶部滚动条区域与导航栏衔接。
- 仅深色模式；可在「微调」中调整玻璃透明度、模糊和背景显影。
- 桌面宽度 ≥1200px 时，服务器卡片每行四列；768px 起卡片统一高 696px，手机端高 720px，回程或本地链路区域固定高 132px。
- 首页可完整展示八个已配置拨测目标，V4/V6 标签紧凑显示；大屏内容容器扩至 1480px。
- 境外节点展示三网回程证据、等级及采集时间；国内节点展示真实拨测摘要。
- 回程等级使用灰、蓝、紫、金四档文字颜色，依次对应不作线路定级、普通线路、优质线路、精品线路。
- 卡片根据节点实际上报的有效地址显示 IPv4、IPv6 或双栈徽标；没有有效地址时不显示，徽标不代表公网连通性。
- 延迟任务根据后台顺序、任务 ID 和节点分配显示；同名任务独立关联，已删除或未分配的历史记录不会混入卡片。
- 支持 IPv4/IPv6 成对目标；确认缺少相应协议时保留该行并显示「—」，有协议但全丢包显示「不可达」，有效零毫秒样本显示「<1 ms」。
- 延迟图表支持「本地、联通、电信、移动」等通用标签；目标由使用者自行配置，公开包不提供测速地址或接口。
- 搜索、卡片/列表视图、服务器详情和历史图表。
- 概览「资产总值」显示节点剩余价值的折合估算，可打开现有账单、月均和年化支出明细；隐藏价格时保持遮罩。
- 可选访客信息展示访问者自己的公网出口、粗略地区、设备及浏览器信息，默认关闭，支持关闭或展开详情。
- 流量预测、流媒体解锁浮窗采用暖色外层与玻璃内卡片，适配窄屏。

「资产总值」可在 **Komari 后台 → 主题设置 → 概览卡片 → 自定义组合** 中启用：在概览卡片 keys 末尾添加 `remainingValue`（与其他 key 用英文逗号分隔）。这个兼容 key 现在显示为「资产总值」，沿用剩余价值折合计算；公开版默认的六个概览指标保持原配置。

## 回程与插件

回程扩展依赖单独安装的 **Transit Route Probe** 插件及节点助手。未安装时保留「等待采集」状态，不会编造线路或延迟。采集失败时保留上次成功结果。管理操作需要有效管理员登录。

NetForecast 和 UnlockTest 是独立插件。主题不包含它们的安装包或重复注入代码；仅在已安装时提供样式适配。主题不会开启节点远控，也不会修改 SSH 权限。

节点的国内或境外分类以地区代码为准。如需暂停某个节点的回程采集，可为它添加独立标签 `route-probe:paused`；不按机器名称匹配。延迟任务由用户在自己的 Komari 后台配置。结果以当前 Komari 主题设置为准；公开包没有预置个人测速节点、机器名称规则、节点 UUID、回程快照或登录凭据。

管理员访问时，主题从受认证的节点列表读取协议信息，并依据匿名接口可见的公开节点 UUID，同步是否上报 IPv4/IPv6 的布尔摘要，供未登录访客显示徽标。摘要不包含 IP 地址，也不包含隐藏节点。公开接口中被隐藏的地址不视为协议缺失；该标记只说明已上报的地址族，不作公网可达性判断。

访客信息开关位于主题设置，默认关闭。开启后，浏览器依次使用 `ipwho.is`、`ipapi.co`、`api.ip.sb` 查询访问者自身的信息；请求不携带站点 Cookie、Referer、节点信息或密钥，第三方仍会看到访问者的公网出口。成功结果在当前浏览器会话缓存 30 分钟，失败缓存 5 分钟，不写入 Komari。宽屏侧边有足够留白时显示详情卡，其他电脑端可从底部展开，手机端滚动时会收起底栏。

Alpine Linux / OpenRC 节点可使用仓库中的 [安装脚本](scripts/install-transit-openrc.sh)，以 root 执行 `sh install-transit-openrc.sh --endpoint https://monitor.example.com`，将示例域名换成自己的 Komari 地址。脚本安装固定版本的上游回程助手及 OpenRC 服务，终端隐藏输入该节点自己的 Agent Token；不需要管理员 API Key。脚本仅适用于已运行 OpenRC 的 Alpine 系统，安装后检查服务状态，采集结果仍需在已配置伴生插件的面板中触发。该脚本属于维护源码，不包含在主题安装 ZIP 中。

## 延迟监测目标地址库

[Zstatic CDN 节点查询](https://www.zstaticcdn.com/) 提供可免费查询的三网省级与市级节点目录，可按地区、运营商及 IPv4 / IPv6 查找目标域名和端口，供使用者自行选择并添加到 Komari。

添加方法：

1. 在目录中选择省份或城市，以及联通、电信、移动等运营商，复制需要的节点地址。
2. 打开 **Komari 后台 → 延迟监测 → 添加任务**。
3. 该目录的节点用于 **TCP Ping**；任务类型选择 **TCP**，按表单要求填写节点域名/IP 和对应端口，不能直接当作 ICMP 目标使用。用途说明见[原作者发布帖](https://www.nodeseek.com/post-68572-1)。
4. 自行设置监测节点、间隔和显示名称；需要四线图表时可使用「本地、联通、电信、移动」等名称。

添加的是目录中选定的节点地址，而不是地址库网站首页。目标可用性及使用条件以资源提供方说明为准。公开包只提供查询入口与添加说明，不内置目标地址、测速接口、共享密钥或任务配置。

## 开发与打包

需要 Node.js 24、npm 和 Python 3。

```sh
npm ci
npm test
npm run check
npm run build
npm run package
```

安装包输出到 `release/Ichigo-Komari-Theme.zip`。推送与主题版本一致的 `v*` 标签可通过 GitHub Actions 构建并创建 Release。

手动运行工作流默认只生成构建产物；勾选 `publish` 才会发布。手动运行始终构建当时 `main` 分支的提交，校验主题与 package 版本一致，再创建缺失的版本标签并上传 Release 附件。已存在的同提交 Release 会覆盖更新同名附件；若标签已指向其他提交，必须先提升版本号。

本仓库包含 Reze 1.2.2 的生产资源和独立 TypeScript 扩展，**不包含原主题完整 Vue 开发源码**。构建重建回程、双栈拨测和访客模块及定制 CSS，并校验卡片、财务明细等生产资源的接入补丁。修改原生产 chunk 后，应统一更新全部 JS/CSS 文件名和引用，避免混用缓存。维护说明见 [BUILD.md](BUILD.md)。

主题内部标识仍为 `Reze-Route`，用于保持已有 Komari 配置和回程结果兼容。
